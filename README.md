# Training Institute Management System

A web-based Training Institute Management System developed using Java,
Spring MVC, JSP, CSS and MySQL.

## Technologies Used

- Java
- Spring MVC
- JSP
- HTML
- CSS
- MySQL
- JdbcTemplate
- JSTL

## User Roles

### Admin
- Student Management
- Course Management
- Batch Management
- Faculty Management
- Attendance Monitoring
- Assessment Monitoring
- Reports

### Faculty
- My Students
- My Batches
- Attendance
- Assessments
- Student Results
- Profile

### Student
- Courses
- Batches
- Attendance
- Assessments
- Results
- Profile

## Architecture

Controller → Service → Repository → MySQL
